# OpportunityX — Student Opportunity Intelligence

OpportunityX is a student-focused platform that brings internships, hackathons, courses, certifications, competitions, workshops and other opportunities into one place.

## Problem

Students often miss valuable opportunities because information is scattered across different websites and platforms.

## Solution

OpportunityX provides a centralized platform where students can:

- Create their student profile
- Discover opportunities
- Get profile-based opportunity matches
- Search and filter opportunities
- Save opportunities
- Track deadlines
- View opportunity details
- Simulate how adding a skill can unlock opportunities

## Key Features

- Student Profile
- Interest & Skill-based Matching
- Personalized Recommendations
- Opportunity Radar
- Search and Filters
- Save Opportunities
- Deadline Tracking
- What-If Skill Simulation
- External Opportunity Links
